# Diplom_1 — Unit-тесты на Java

## О проекте
Учебный проект по автоматизации тестирования.  
Написаны unit-тесты для проверки бизнес-логики Java-приложения.

## Стек технологий
- Java 11
- JUnit 4
- Mockito
- Maven

## Что протестировано
- Создание и управление заказом
- Расчёт стоимости с учётом скидок
- Валидация вводимых данных
- Граничные значения и исключения

## Запуск тестов
```bash
mvn clean test
